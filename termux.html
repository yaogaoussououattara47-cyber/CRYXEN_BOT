GUIDE DE DÉPLOIEMENT

CRYXEN_BOT

Installation complète sur Termux
termux — bot-whatsapp
1️⃣ Mise à jour Termux et outils de base
$ pkg update && pkg upgrade -y
$ pkg install git unzip wget -y
2️⃣ Dépendances supplémentaires
$ pkg install python make clang ffmpeg libvips -y
3️⃣ Accès au stockage interne
$ termux-setup-storage
4️⃣ Installer les paquets nécessaires
$ pkg install nodejs git -y
5️⃣ Vérifie que tu vois le fichier du bot
$ ls ~/storage/downloads
6️⃣ Copie et extraction du bot
$ mkdir ~/bot-whatsapp
$ cp ~/storage/downloads/Cryxen_bot.zip ~/bot-whatsapp/
$ cd ~/bot-whatsapp
$ unzip Cryxen_bot.zip
7️⃣ Installation des modules
$ cd Cryxen_bot
$ npm install ytdl-core
8️⃣ Lancement du bot
$ node index.js
